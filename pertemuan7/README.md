## Struktur
- `controllers/ProdukController.php`: mengatur alur aplikasi.
- `models/ProdukModel.php`: mengakses data produk di MySQL.
- `views/produk/`: halaman daftar, tambah, dan edit produk.
- `index.php`: halaman utama.
- `koneksi.php`: koneksi database.
- `database.sql`: pembuatan database dan tabel.

## Cara menjalankan
1. Simpan folder `pertemuan7` di dalam `C:\\xampp\\htdocs\\prak-pbw-b-muhammad-al-farel-putra-hermawan-4524210113\\`.
